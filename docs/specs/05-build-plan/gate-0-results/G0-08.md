# G0-08 — Arc gas and contract-size limits

- **Date:** 2026-10-20
- **Result:** pass. The observed runtime-code limit is 24,576 bytes. No SCR required.
- **Funds spent:** none. RPC calls were read-only; deployments used local `arc-anvil` only.

## RPC gas limits

`arc-cast block latest --json` returned `gasLimit = 0x1c9c380` (30,000,000) on:

| RPC | Observed block |
|---|---:|
| `https://rpc.testnet.arc.io` | 68,185,485 |
| `https://rpc.mainnet.arc.io` | 26,948,369 |

## Runtime-code boundary

On `arc-anvil --network arc --port 18546` (local chain 31337), a generated initcode
returned a zero-filled runtime of the requested length. The initcode copied the
runtime payload with `CODECOPY`, then returned it. No private key was used; the
local anvil account was unlocked by the node.

| Requested runtime | Local result |
|---:|---|
| 24,576 bytes | Deployment succeeded; `arc-cast code` returned 24,576 bytes |
| 24,577 bytes | Gas estimation refused with `CreateContractSizeLimit` |

The read-only testnet `arc-cast estimate --create` call with the same 24,577-byte
runtime initcode also reverted with `CreateContractSizeLimit` (RPC error code 3).

The PRD 10 clean build measured `CzarVault` at 14,540 runtime bytes and
`CzarVaultFactory` at 20,747 runtime bytes, both below this limit.
