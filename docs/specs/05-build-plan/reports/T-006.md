# T-006 — `@czar/schemas`

## Result

Implemented the schema package against every schema currently in spec 02. Runtime validators load and compile the canonical Draft 2020-12 files with Ajv, resolve the shared `common.schema.json` definitions, and validate every protocol example. TypeScript interfaces and named validators are generated from the same JSON Schema files. `privacyClassOf` follows nested and cross-file references; `assertNoLocalOnly` validates against the selected schema and rejects local-only fields.

The checkout contains 28 schema files, including 27 data schemas and `common.schema.json`, which is a definitions bundle rather than a data object. The definitions bundle is registered with Ajv but does not expose a pass-all `validateCommon` function.
