# T-009 — `@czar/api-contract`

## Result

Implemented an OpenAPI contract harness for the public and local API documents. It parses both YAML files, resolves and checks internal and relative file `$ref` values recursively, and compiles request and response validators keyed by `operationId`. `validateRecordedExchange` checks captured request and response bodies against the declared status response, including wildcard status responses and declared no-body responses.

Tests confirm that every parsed operation ID is registered, that the MCP `quote` and `pay` request and response schemas accept and reject the same fixtures as their route validators, and that the reviewed `ObjectiveStatusValue`, `getJobBrief`, and `completeModelCall` 409 response are present.
